# 스마트폰 기반 임질 진단 시스템

LAMP-CRISPR 형광 반응 결과를 스마트폰으로 촬영해 자동 판독하는 시스템입니다.
YOLOv8로 튜브와 반응 영역(ROI)을 검출하고, ROI의 형광 강도 비율로 양성/음성을 판정합니다.

성균관대학교 생명공학대학 주관 교내 경진대회 출품작 (2025).

---

## 판정 원리

한 장의 사진에 **음성 대조군(NC)을 위쪽, 검사 시료를 아래쪽**에 함께 담아 촬영합니다.
두 튜브를 같은 조명·같은 카메라로 동시에 찍기 때문에, 둘의 비율을 쓰면
기기 차이와 조명 차이가 상쇄됩니다. 절댓값 대신 비율을 쓰는 이유입니다.

```
사진 입력
   ↓
YOLOv8 검출 (클래스: tube, roi / conf ≥ 0.70)
   ↓
튜브 내부에 완전히 포함된 ROI만 매칭, 튜브당 최고 conf ROI 1개 선택
   ↓
ROI 중심 y좌표로 정렬  →  위 = NC, 아래 = 시료
   ↓
각 ROI의 G채널 95백분위수 계산  →  Iu, Il
   ↓
ratio = Il / Iu
   ↓
ratio ≥ 1.148  →  양성
```

### 주요 파라미터

| 파라미터 | 값 | 근거 |
|---|---|---|
| `CONF_MIN` | 0.70 | `step1_conf_explorer.py` 의 임계값 스윕 |
| 채널 / 지표 | G채널 p95 | `step2_2.py` 의 7개 채널 × 2개 지표 비교 (Cohen's d 최대) |
| `ABS_NEG_CUTOFF` | 221.0 | `step3_threshold_analysis.py` 의 음성 기준선 |
| `RATIO_THR` | 1.148 | `step4_pair_solo_relation.py` |

G채널을 쓰는 이유는 FAM 형광의 발광 파장이 녹색 영역이기 때문이고,
평균 대신 95백분위수를 쓰는 이유는 ROI 안에 어두운 배경 픽셀이 섞여 있어
평균이 신호를 희석시키기 때문입니다.

## 저장소 구조

```
├── app.py                      Streamlit 웹앱 (배포본)
├── models/weights.pt           YOLOv8s 학습 가중치
├── analysis_code/              분석 파이프라인
│   ├── step1_conf_explorer.py      검출 임계값 스윕
│   ├── step2_2.py                  채널 선정 + Welch t-test
│   ├── step3_threshold_analysis.py 음성 기준선 산출
│   ├── step4_pair_solo_relation.py 쌍 비율 분석
│   ├── ROC.py                      ROC / AUC
│   └── step_1117.py                음성-음성 쌍 검증
├── paths.py                    공통 경로 설정
└── requirements.txt
```

이미지 데이터셋과 분석 산출물은 용량 문제로 저장소에 포함하지 않았습니다.

## 모델

- 아키텍처: **YOLOv8s**
- 클래스: `tube`, `roi` (2개)
- 학습: 300 epoch 설정, patience 90으로 **213 epoch에서 조기 종료** (best는 123 epoch)
- 입력 크기: 640
- 데이터셋 관리: Roboflow

## 한계

이 프로젝트는 학부생 팀이 약 3개월 동안 수행한 교내 대회 출품작입니다.
아래는 이후 코드와 결과를 다시 검토하며 직접 확인한 한계들입니다.

**검증 범위**

- 검출 한계(LOD)를 확립하지 못했습니다. 농도 의존적 형광 패턴이 명확히 나타나지 않아,
  특정 농도에서 검출되었다는 단일 관찰만 있고 반복 측정에 근거한 LOD는 없습니다.
- 특이도 검증에 인간 gDNA만 사용했습니다. 표적으로 삼은 `porA` pseudogene 은 본래
  임질균을 다른 *Neisseria* 종과 구별하기 위한 것이므로, 근연종(*N. meningitidis* 등)에
  대한 교차 반응 확인이 필요하나 수행하지 못했습니다.
- 촬영 조건 최적화 실험 일부는 조건당 n=1 로 수행되어, 통계적 비교의 근거가 되기
  어렵습니다.

**데이터 분할**

- YOLO 학습 데이터를 이미지 단위로 분할했습니다. 같은 튜브를 여러 각도·조건으로
  촬영한 이미지가 train 과 test 에 나뉘어 들어갔을 가능성이 있으며, 이 경우
  검출 성능이 낙관적으로 평가됩니다.

**시스템 견고성**

- 양성 판정 마진(약 15%)이 기기 간 신호 편차(최대 약 12%)와 비슷한 크기입니다.
  기기에 따라 경계 근처 시료의 판정이 달라질 수 있습니다.
- 튜브를 뒤집어 놓은 경우(양성을 위쪽에) 경고는 표시되지만 판정은 그대로 출력됩니다.
  안전상 판정 불가로 처리하는 것이 맞습니다.

**임상적 위치**

- 실제 임상 검체가 아닌 합성 표적 DNA로 검증했습니다. 진단 도구가 아니라
  개념 검증(proof-of-concept) 수준입니다.
