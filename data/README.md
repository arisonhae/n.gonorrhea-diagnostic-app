## 촬영 조건

| 항목 | 값 |
|---|---|
| 촬영 환경 | mini darkroom box 내부 |
| 조명 | Blue LED transilluminator (BluPAD BP001CU, BIO-HELIX) |
| 조명 강도 | 3단계 (80,846 lux) |
| 필터 | 앰버 필터 |
| 거리 | transilluminator 표면으로부터 **20 cm 높이** |
| 광학 배율 | **2x** |

조건 선정 근거는 [analysis/pilot/README.md](../analysis/pilot/README.md) 에 있습니다.

**위쪽이 음성 대조군(NC), 아래쪽이 검사 시료**입니다.
이 배치는 판정 로직의 전제이므로 반드시 지켜야 합니다.

기기 호환성 검증(`test_all`)에는 iPhone 13 Pro 외에 iPhone 13,
Galaxy Note 8 로 촬영한 이미지도 포함되어 있습니다.

## 폴더 구조

`NGD_DATA_ROOT` 아래의 `dataset/` 이 분석 파이프라인이 읽는 정제본이며,
**총 238장**입니다.

```
dataset/
├── solo/                     튜브 1개 이미지 (절댓값 분석용) — 110장
│   ├── train/
│   │   ├── neg/                40장
│   │   └── pos/                40장
│   └── test/
│       ├── neg/                15장
│       └── pos/                15장
│
├── pair/                     튜브 2개 이미지 (비율 분석용) — 46장
│   ├── neg_pos/                20장  위=NC, 아래=양성 시료
│   └── neg_neg/                26장  위=NC, 아래=음성 시료 (위양성 확인용)
│
├── qc_test/                  촬영 품질 이상 이미지 — 60장
│   ├── error_splash/           20장  용액이 튀어 ROI가 흩어진 경우
│   ├── error_blur/             20장  초점이 맞지 않은 경우
│   └── error_light/            20장  빛반사·빛누출이 심한 경우
│
└── test_all/                 기기 호환성 최종 검증 — 22장
    ├── neg_pos_galaxynote8/     9장
    ├── neg_pos_iphone13/        8장
    └── neg_pos_iphone13pro/     5장

저장소 안:
data/samples/                 예시 이미지 9장 (앱 동작 확인용)
```

`solo` 는 형광 절댓값의 분포를 보기 위한 것이고,
`pair` 는 NC 대비 비율을 계산하기 위한 것입니다.
`qc_test` 는 검출 실패 상황에서 시스템이 오판하지 않고
"판정 불가"로 빠지는지 확인하는 데 사용했습니다.

`test_all` 은 **평가 전용**입니다. 임계값을 정하는 단계(step1~4)에서는
절대 사용하지 않습니다.

`pair/neg_neg` 26장 중 2장은 ROI 가 하나만 검출되어 비율을 계산할 수 없어
분석에서 제외했습니다. 제외 사유는 `results/step4_ratio/pair_analysis.csv` 의
`note` 열에 `ROI_PARTIAL` 로 기록되어 있습니다.

## 라벨 규칙

- `solo` 이미지의 라벨은 **폴더명**(`pos` / `neg`)에서 가져옵니다.
- `pair` 이미지는 **위치**로 역할이 정해집니다. 위 = NC, 아래 = 시료.
  파일 안에 라벨 정보가 없으므로, 촬영 시 순서를 지키는 것이 중요합니다.

## YOLO 학습 데이터

튜브·ROI 검출 모델 학습에는 Roboflow 로 관리한 별도 데이터셋을 사용했습니다.

- 데이터셋: `hajamboree/tube_detection-thlv6` **v8** (2025-11-04)
- 클래스: `tube`, `roi` (2개)
- 어노테이션: bounding box
- 구성: 원본 300장을 train 200 / valid 50 / test 50 으로 분할한 뒤
  train 에만 증강(회전 ±15°, 밝기 ±15%)을 3배 적용 → **600 + 50 + 50 = 700장**

증강을 적용하지 않은 원본 300장 버전(v10)도 함께 배포합니다.

**동일 원본이 여러 split 에 들어간 사례는 없습니다.** 파일명 앞부분이 겹치는
경우가 있으나 서로 다른 이미지이며, 두 촬영 기기에서 같은 파일명 규칙을 쓴
결과입니다. 확인 과정은 [CHANGELOG.md](../CHANGELOG.md) 를 참고하십시오.

## 논문 기재와 다른 점

제출 논문(2025년 11월)은 수정하지 않았으므로, 실제 데이터와 다른 부분이
있습니다. 상세 내역은 [CHANGELOG.md](../CHANGELOG.md) 에 있습니다.

| 항목 | 논문 | 실제 데이터 |
|---|---|---|
| QC 세트 | 4종 (`error_blur`, `error_light`, `leakage`, `error_splash`) 각 10장 | **3종** 각 20장 |
| 회전 각도 실험 | 16장 | 13장 |
| 다중 시료 배치 실험 | 20장 | 21장 |
| `test_all` | 기기당 8장 (24장) | 정제 후 **22장** (원본 24장) |

QC 세트에 대하여: 논문 2.7.2 는 4종으로 적었으나, 같은 논문 2.7.1 은
`pair_light_leakage` 를 한 항목으로 보아 3종을 셉니다. 실제 데이터는 3종이며,
2.7.2 가 이름 하나를 둘로 나눠 적은 것으로 보입니다.
